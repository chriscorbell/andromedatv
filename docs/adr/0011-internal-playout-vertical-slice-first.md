# Internal playout vertical slice first

AndromedaTV will first prove a local Vertical Slice against the Andromeda Library rooted at `/nas/media/andromeda`, scanning `series/` and `bumps/`, classifying Episode Assets and Bump Assets, creating persistent Channel State, generating the Round-robin Series Queue and Bump Rotation, serving `/api/schedule`, and producing local Live HLS Output for `/iptv/session/1/hls.m3u8`. The slice may use a temporary Series Allowlist to keep the initial proof small while still using actual library files. The slice is not complete until the existing web UI can display the generated schedule and play through episode-to-bump-to-episode transitions without requiring `ERSATZTV_BASE_URL`. Tiny generated media fixtures may support automated tests, but the milestone is proven against the actual library files; AniDB matching, Jellyfin metadata seeding, Intel Arc Hardware Transcoding, and production deployment changes will come after this local ErsatzTV replacement works end to end.
